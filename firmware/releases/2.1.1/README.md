# 火眼固件 2.1.1

发布日期：2026-11-01

适用硬件：2026-10 新载板，GD32F407VKT6，INA228 + 2mΩ 分流，W5500，
24V 低压监测原型。

## 版本内容

- INA228 串口和 HTTP 上报提高电流/电压精度，并输出 `raw20`。
- 增加电流增益 PPM 与零点微安校准参数。
- 电流安全阈值为 `1.2A WARNING`、`1.5A ALARM`；WARNING 不断载，
  ALARM/SHUTDOWN 断开继电器。
- HTTP socket 使用非阻塞 `poll()` 等待连接、发送和接收，硬超时为 3 秒。
- W5500、静态 IPv4、16 个 TCP 预分配连接和网络上报已编入最终镜像。

## 烧录文件

- `fireeye_2.1.1_20261101.hex`
- `fireeye_2.1.1_20261101.bin`
- `SHA256SUMS`

优先使用 HEX 文件。烧录后串口应出现 `FireEye v2.1.1`、W5500 初始化和
`FireEye net: eth0 up, ip=192.168.1.200`。

## 当前边界

当前硬件是 24V 低压监测原型，F1 为 2A 保险丝，禁止进行 5A/8A 实流测试。
INA228 完整量程、零点与增益标定、告警断载、掉电断载、5 分钟以上持续网络
稳定性和路由环境仍应按 `docs/current/` 中的验收边界继续确认。
