# 火眼固件 2.1.2

发布日期：2026-11-03

适用硬件：2026-10 新载板，GD32F407VKT6，INA228 + 2mΩ 分流，W5500，
24V 低压监测原型。

## 版本内容

- 修复过流 ALARM 自动重合闸问题。
- 电流达到 ALARM 后保持锁存；继电器断开、采样电流归零或温度恢复都不会
  自动重新接通负载。
- 排除过流原因后，按板载 K2 人工复位，系统恢复 NORMAL 并重新开始监测。
- 人工复位时同步清空电流滤波和阈值历史，避免旧高电流样本导致立即重复动作。
- 温度告警仍保留降温自动恢复逻辑。
- 保持 `1.2A WARNING`、`1.5A ALARM`、W5500 HTTP 上报和 INA228 校准接口。

## 烧录文件

- `fireeye_2.1.2_20261103.hex`
- `fireeye_2.1.2_20261103.bin`
- `SHA256SUMS`

优先使用 HEX 文件。烧录后串口应出现 `FireEye v2.1.2`。

## 过流恢复操作

1. 系统进入 ALARM 并断开负载后，不要直接按复位继续带载。
2. 先断开或更换异常负载，排除过流原因。
3. 确认输入、端子和负载安全后，按板载 K2。
4. 如果过流条件仍然存在，系统会在连续防抖后再次锁存 ALARM。

## 当前边界

当前硬件是 24V 低压监测原型，F1 为 2A 保险丝，禁止进行 5A/8A 实流测试。
INA228 完整量程、零点与增益标定、5 分钟以上持续网络稳定性和路由环境仍需
继续验证。
