# 火眼——电动自行车充电电气安全监测终端

## 一、作品简介

面向物业、街道与消防部门，部署在小区充电区/楼道充电点的智能监测终端：基于 openvela 与兆易创新 GD32F470V-START（官方已适配开发板），实时采集充电回路电流、温度与漏电状态，超限即时声光报警、联网上报并本地存证，从电气侧阻断电动自行车充电火灾。

亮点：

- **电气侧防控**：电流异常与温升是电池热失控的最直接前兆，监测维度比视频识别更本质；
- **端侧离线闭环**：感知、判断、报警全程本地，断网仍可报警与存证；
- **无摄像头依赖**：规避视觉算力短板与隐私争议，工程可靠性高。

## 二、选题方向

**AI 硬件产品创新**。

理由：在 openvela 官方已适配的 GD32F470V-START 上开发应用层作品，聚焦多传感采集、信号处理与端侧告警引擎，赛道风险最低；以真实监管痛点（电动自行车入户充电火灾）切入，商业与政策价值清晰。
