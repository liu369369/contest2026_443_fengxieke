# 火眼——电动自行车充电电气安全监测终端（作品介绍）

> **当前口径（2026-10-29）**：当前交付物是24V低压充电安全监测原型，使用
> INA228 + 2mΩ分流、独立12V终端供电和COM→NO继电器。INA228、NTC、OLED、
> 声光输出和基础负载电流已验证；W5500 PHY尚未建立Link。当前硬件不能直接
> 适配主流48V/60V/72V充电器，也不能进行5A/8A实流验收。
> 完整边界见 [current/scope-and-roadmap.md](current/scope-and-roadmap.md)。

## 一、作品概述

**火眼** 是一款面向充电场景的安全监测原型，基于 **openvela** 与
**兆易创新 GD32F470V-START（板载芯片 GD32F407）**。当前版本实时采集
24V被测回路的电流、母线电压和温度，通过端侧算法判定异常，触发声光报警和
继电器断载；联网上报和上位机事件留痕已完成设计，但当前W5500模块PHY无Link，
尚未完成端到端验收。

## 二、解决的真实问题

电动自行车充电安全需要同时关注电流异常、连接器发热和电池温升。本项目从
电气参数切入，先以24V低压回路完成端侧“采样—判断—告警—断载”闭环，为后续
升级到主流48V充电器所需的更高电压和电流等级验证软硬件架构。

## 三、技术方案

### 1. 应用层（`app/fireeye/`）
- **滤波模块**：滑动平均 + 一阶低通，去除采样噪声；
- **阈值判定模块**：单阈值 + 趋势（线性回归斜率）+ 连续 N 点防抖；
- **状态机**：正常→预警→报警→断电，支持复位；
- **主程序**：10Hz 采样循环，融合电流/温度，驱动报警与上报。

### 2. 新载板
- **电流**：INA228，I2C1 地址 `0x40`，2mΩ 分流，固件直接读取 VSHUNT；
- **供电**：终端由独立 12V 电池供电，24V 回路只作为被测对象；
- **负载执行**：常开继电器，正常时励磁接通负载，报警或掉电时释放断开；
  当前3/5脚已完成短接返修，基础带载通路通过；
- **显示**：SSD1306 OLED，当前新版仪表盘已编译，待烧录确认；
- **当前电源边界**：F1为2A保险丝、D1为40V SS54；实流测试不宜超过1.5A连续，
  禁止直接测试5A/8A；
- **工程复核**：24V主功率路径已通过EasyEDA实时工程确认，`24V_IN`和
  `LOAD_P`全部60mil，`24V_SW`主功率线为60mil；10mil线仅用于INA228采样。

### 3. 新硬件适配（`docs/adaptation_F407.md`）
- 将 openvela 移植到**官方未完整支持的 GD32F407**：补齐芯片头文件、引脚映射、内存映射、Flash 编程扇区与 CMake 分发；
- 芯片实测为 **GD32F407VK**：`FMC_SIZE=3072KB`（3MB Flash）、SRAM 192KB、主频 168MHz（实测寄存器读数为准）；
- 时钟：25MHz 晶振 → **168MHz**（PLLPSC=25/PLLN=336/PLLP=2/PLLQ=7，VCO 336MHz），修复了此前 PLL 预分频错误导致的启动死锁；
- 串口：**USART0 = PB6(TX)/PB7(RX)，115200-8-N-1**；板上 GD-Link 无虚拟串口，需外接 3.3V USB-TTL（JP6 第 16/13 脚）；
- 已实现 openvela 在 F407 上**编译通过、烧录运行**：固件包含火眼应用与 OLED 模块（`nm` 验证符号），
  RCU_PLL 常量实测 `0x07405419`；实机接 3.3V USB-TTL 后**串口正常输出 `NuttShell (NSH)` 与 `nsh>` 提示符**，
  火眼应用可运行；板级 LED 自检（PC6 心跳）用于快速判断系统是否启动。

### 4. 端到端验证
- GD32实机已验证INA228、OLED、NTC、声光输出和基础负载电流；
- 1.00V电源时约`0.065A / VBUS 0.7V`，2.00V时约`0.17A / VBUS 1.6V`；
- W5500 SPI/MACRAW正常，但PHY无Link，网络链路未通过；
- PC端算法原型仍可用于算法回归，不作为硬件验收依据。

## 六、亮点

- **电气侧防控**：监测热失控直接前兆（电流/温升），比视频识别更本质；
- **端侧离线闭环**：感知、判断、报警全程本地，断网可用；
- **新硬件适配**：将 openvela 迁移到官方未支持的新芯片（GD32F407），作为适配成果；
- **多模块算法**：滤波 + 阈值/趋势 + 防抖 + 四态状态机，工程化程度高。
- **可验证的升级路径**：下一代硬件目标为48V锂电池充电器常见的60V/5A范围。
