# 火眼——电动自行车充电电气安全监测终端（作品介绍）

## 一、作品概述

**火眼** 是一款部署在小区充电区/楼道充电点的智能监测终端，基于 **openvela** 与 **兆易创新 GD32F470V-START（板载芯片 GD32F407）**。它实时采集充电回路的**电流、温度与漏电**状态，通过端侧算法判定过流/超温/漏电异常，触发**声光报警、联网上报与本地存证**，从电气侧阻断电动自行车充电火灾。

## 二、解决的真实问题

电动自行车入户充电引发的火灾事故频发（电池热失控是主因）。传统视频识别侧重"看得见"；本作品从**电气参数**切入——**电流异常与温升是热失控最直接的前兆**，监测维度更本质、更可靠，且**端侧离线闭环**（断网仍可报警与存证）。

## 三、技术方案

### 1. 应用层（`app/fireeye/`）
- **滤波模块**：滑动平均 + 一阶低通，去除采样噪声；
- **阈值判定模块**：单阈值 + 趋势（线性回归斜率）+ 连续 N 点防抖；
- **状态机**：正常→预警→报警→断电，支持复位；
- **主程序**：10Hz 采样循环，融合电流/温度/漏电，驱动报警与上报。

### 2. 新硬件适配（`docs/adaptation_F407.md`）
- 将 openvela 移植到**官方未完整支持的 GD32F407**：补齐芯片头文件、引脚映射、内存映射、Flash 编程扇区分发；
- 时钟：25MHz 晶振 → **168MHz**（PLLM=25/PLLN=336/PLLP=2/PLLQ=7），与官方 SDK 一致；
- 已实现 openvela 在 F407 上**编译通过、GD-Link 烧录成功、固件包含火眼应用**（`strings` 验证 fireeye 符号在固件中）；串口 UART 已能输出。

### 3. 端到端验证
- PC 端算法原型 `app/fireeye_prototype/algorithm_prototype.py`：模拟电流/温度，验证"滤波→阈值→状态机→报警"，输出 57 次报警 + 可视化曲线（`fireeye_algorithm_results.png`）。

## 六、亮点

- **电气侧防控**：监测热失控直接前兆（电流/温升），比视频识别更本质；
- **端侧离线闭环**：感知、判断、报警全程本地，断网可用；
- **新硬件适配**：将 openvela 迁移到官方未支持的新芯片（GD32F407），作为适配成果；
- **多模块算法**：滤波 + 阈值/趋势 + 防抖 + 四态状态机，工程化程度高。
