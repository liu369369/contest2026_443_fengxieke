# 新载板上板验收顺序

首次上电不要直接运行旧演示流程。按以下顺序逐项记录结果。

## 1. 静态检查

- 万用表检查 12V 输入、5V、3.3V 对地是否短路。
- 检查 INA228、OLED、W5500 供电脚和地。
- 检查 2mΩ 分流电阻、继电器 COM/NO、负载端子接线。
- 确认 12V 电池和 USB 不同时接入。

## 2. 空载上电

- 不接负载，只给 12V 电池。
- 观察是否只有预期的一次继电器动作；记录是否出现连续抖动或负载导通脉冲。
- 蜂鸣器应保持关闭。
- 测量 12V、5V、3.3V。

## 3. 总线与传感器

```text
nsh> i2c bus 1
nsh> fireeye current
```

期望：

- INA228 总线地址 `0x40`。
- 厂商 ID `0x5449`。
- 设备 ID 的高 12 位为 `0x228`，最低 4 位是版本号。
- 空载电流接近 0，母线电压应为实际被测电压量级。

## 4. 输出与负载

```text
nsh> fireeye test
nsh> fireeye level
```

逐项确认蜂鸣器、报警灯和继电器动作。继电器必须按“接通负载/断开负载”记录，不只记录 GPIO 高低。

## 5. 告警闭环

分别模拟过流和过温，确认：

- NORMAL：负载接通。
- WARNING：负载保持接通。
- ALARM：负载断开，声光报警。
- 人工复位后故障仍存在时，系统应重新进入告警，不能永久屏蔽故障。
- 拔掉 INA228、NTC 或破坏 I2C 通信后，连续 3 个采样周期应进入 ALARM 并断开负载。
- 掉电时负载断开。

## 6. 网络

新 W5500 单独验证：

- 芯片版本读取。
- 固定 MAC 写入和回读。
- PHY link 状态。
- 本机 IP、掩码和路由。
- HTTP `POST /api/data` 往返。

以上全部通过后，材料才可写“新载板联调通过”。
