# 火眼 2.1.2 过流锁存修复

更新日期：2026-11-03

## 问题现象

电流达到 ALARM 后继电器断开，采样电流随负载断开降至接近零。原状态机把该
NORMAL 样本解释为故障解除，重新吸合继电器；负载电流再次超限后又断开，形成
反复通断。

## 修复内容

- 过流 ALARM 在 `fireeye_main.c` 中增加锁存状态。
- 继电器断开后即使电流回落，系统仍保持 ALARM 并持续断开负载。
- 人工按 K2 才清除过流锁存。
- 复位时同步清空电流滤波器和阈值历史。
- 温度告警仍保留降温自动恢复。

## 上板复核结果

1. 模拟超过 1.5A 的受控负载，确认进入 ALARM 并断载。
2. 断载后观察至少 30 秒，确认不会自动重合闸。
3. 保持故障负载，按 K2 后应再次进入 ALARM。
4. 移除异常负载并复位，确认恢复 NORMAL。
5. 复核 NTC 超温仍可自动恢复为 NORMAL。

2026-11-03 用户确认以上验证通过。外接按键与板载 K2 并联接入 PA0-GND。
