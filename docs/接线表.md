## 一、主接线表

### 1. 传感器输入（ADC0，12bit）

| 信号 | 板上引脚 | 排针位置 | 接到哪里 | 备注 |
|---|---|---|---|---|
| 电流采样 | PA4（ADC0_IN4） | JP5-7 | ACS712 输出经 10k+10k 分压后的中点 | ACS712 用 **5V** 供电；**分压电阻必须接**，5V 输出直连会打坏引脚 |
| 温度采样 | PA6（ADC0_IN6） | JP5-9 | 10kΩ 上拉 + NTC 分压的中点 | NTC 10K B3950，分压上端接 3V3 |

### 2. 输出执行器

继电器**触点侧**（和线圈电源是两回事）：

| 触点 | 接哪里 | 为什么 |
|---|---|---|
| COM | 电源正（视负载而定） | 公共端 |
| **NC**（常闭） | 负载（风扇 / 充电回路） | 正常态导通；报警时继电器吸合 → NC 断开 → **真正断电** |
| NO（常开） | 不用 | 若接 NO，就变成"报警才通电"，与"联动断电"相反 |

判断接对没有（2026-09-18 重新定标）：上电、**未运行 fireeye** 时风扇不转（板级 bring-up 默认吸合、负载断电）；运行 fireeye 进入 `state=NORMAL` 后风扇转；报警时停。IN 悬空 = 模块释放 = 负载通电，所以 IN 线脱落会失去断电能力，建议 IN—5V 加 10kΩ 上拉。

| 信号 | 板上引脚 | 排针位置 | 接到哪里 | 触发极性（实机实测） |
|---|---|---|---|---|
| 继电器 IN | PB0 | JP5-13 | 继电器模块 IN | **高电平触发**（`FIREEYE_RELAY_ACTIVE_LOW=0`，2026-09-18 实测定标）；模块 **VCC 接 5V**（JQC-3FF-S-Z，5V 线圈）。建议 IN—5V 加 10kΩ 上拉，悬空时默认吸合=断电 |
| 蜂鸣器 + | PB1 | JP5-16 | 蜂鸣器正极 | **低电平触发**（`FIREEYE_BUZZER_ACTIVE_HIGH=0`）；裸蜂鸣器建议加 NPN 三极管 + 1kΩ 基极电阻 |
| 报警灯 IN | PD9 | JP5-31 | 报警灯模块信号脚 | **高电平触发**（`FIREEYE_LED_ACTIVE_HIGH=1`）；3 脚模块，VCC 接 5V |

## 二、两个必须自搭的分压电路

```
温度：3V3 ──[10kΩ]──●──[NTC 10K B3950]── GND        ● → PA6 (JP5-9)
电流：ACS712 OUT ──[10kΩ]──●──[10kΩ]── GND           ● → PA4 (JP5-7)
```

## 二之二、电流检测怎么串进回路

> 示意图见 `docs/接线图_电流检测.png`（上：功率侧串联；下：信号侧分压与引脚）。

ACS712 是**串联型**传感器：被测电流必须**流经模块本身**的两个大电流端子（丝印 IP+ / IP−，
有的模块标 In+ / In−），不是并联、也不是钳形表那种夹线。

本项目实验台的实际接法（12V 风扇当负载）：

```
 12V 电源 +  ──► 继电器 COM ──► 继电器 NC ──► ACS712 IP+ ──► ACS712 IP− ──► 风扇 +
                                                                              │
 12V 电源 −  ◄──────────────────────────────────────────────── 风扇 − ────────┘
```

- 继电器和 ACS712 谁在前谁在后都行，**关键是两个都串在这同一条回路里**；
- 继电器触点用 **COM + NC**：正常态导通、报警时吸合断开，风扇立刻停；
- 12V 回路与开发板之间由 ACS712 和继电器触点隔离，**不需要把 12V 接到开发板**；
  只有 ACS712 的信号侧 VCC / GND / OUT 接开发板，且 GND 与开发板共地。

信号侧三根线：

| 模块丝印 | 接到 | 说明 |
|---|---|---|
| VCC | 5V（外部电源） | 模块工作电压，静态输出 2.5V |
| GND | 开发板 GND（JP6-1） | 必须共地，否则 OUT 没有参考电平 |
| OUT | 10k+10k 分压中点 → PA4（JP5-7） | **不能直连 PA4**，输出可达 4.5V |

### 方向与正负号

串联方向决定读数的正负：接反了读数会变负（`读数是负数 → IP+ / IP− 对调`）。
开机时的零点校准会自动扣掉静态偏置，所以正负不影响报警功能，只是"充电方向读正数"更直观。

### 小电流为什么读数很小

30A 版灵敏度 66mV/A，再经 10k+10k 分压，等效 **33mV/A**；ADC 是 3.3V / 12bit，
即约 **0.8mV ≈ 0.024A** 一个码。12V 风扇负载只有 0.16A 量级，折算下来输出只变化约 5mV、
也就是 6~7 个 ADC 码，自然容易毛刺。

所以演示"过流"不用真去推 30A，而是把 ACS712 的输出拔掉、用两个 10kΩ 把 3V3 分压成
1.65V 注入到 PA4 那一点——对应 1.65V − 零点（实测约 1.16V）= 0.49V ≈ 15A（按理想零点 1.25V 算则是 12A），两种都能稳定触发过流报警。
这一点在演示视频里要如实说明是"等效电压注入模拟"。

### 验证串对了没有

| 现象 | 说明 |
|---|---|
| 开机串口打印的电流零点电压 1.16~1.25V | 分压与 5V 供电正常；ACS712 输出 = Vcc/2，理论值 1.25V，2026-09-18 实测 1.161V（对应 5V 实际约 4.64V）|
| NORMAL 且负载通电时读数接近实际负载电流（本项目风扇约 0.1~0.2A 量级） | 传感器串在回路里，且在测同一条回路 |
| 拔掉负载或断开回路后读数回到 0 附近 | 正常 |
| 读数是负数 | IP+ / IP− 接反，两根线对调 |

## 五、踩过的坑

1. **ACS712 输出必须分压**：它是 5V 供电、输出 0.5~4.5V，直连 PA4 会损坏引脚。
2. **OLED 的 SDA/SCL 容易接反**：接反的表现是 `OLED init FAILED (-5)`，可用 `i2c bus 1` 扫描确认。
3. **模块触发极性**：继电器是**高电平触发**（2026-09-18 用 IN 悬空 vs 接 PB0 重新定标，09-13 那条低电平结论作废）、蜂鸣器低电平触发、报警灯高电平触发，
   换模块后若动作相反，改板级宏重新编译即可（`FIREEYE_*_ACTIVE_*`）。
4. **不要接 5V 到 OLED / W5500 的 3.3V 脚**。
5. **只烧固件不跑应用**时，netinit 会把 eth0 配成 10.0.0.2/24；跑起火眼应用后是 192.168.1.200/24、上报服务器 192.168.1.100。
