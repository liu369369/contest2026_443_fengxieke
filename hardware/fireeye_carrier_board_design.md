## 三、电路方案

### 3.1 电源树

> **2026-10-11 决策：载板独立供电。** 板子用 12V 锂电池供电，24V 只当被测回路。
> 好处是板子自耗完全不经过分流电阻，可调电源显示的电流与 INA228 读数一致（不必再解释几十 mA 自耗）。

```
【板子电源，与下面完全独立】
12V 锂电 → DC 座 J3 →（D4 防反接，可选）→ U1 MP1584EN (12V→5V)
                                                  ├─ 继电器线圈 / 蜂鸣器 / 报警灯（5V）
                                                  └─ U2 AMS1117-3.3 (5V→3.3V)
                                                        ├─ INA228 / OLED / W5500 / I2C 上拉
                                                        └─ 母座 JP6-2（经 3V3 LINK 跳线）→ START 板 3V3

【被测回路】
24V 端子 J1 → F1 → D1 → R1(2mΩ) → 继电器 COM→NO → J2 → 负载 → 回 GND
```

- 12V 输入对 MP1584（4.5-28V）**余量充足**，不再是 24V 那种贴着上限的状态。
- **主控供电（2026-10-11 决定：不加跳线）**：载板 3.3V 直接经母座 JP6-2 送到 START 板 3V3。
  - **演示**：只给 12V 电池，不插 USB。
  - **调试**：插 USB 时把 12V 电池的 DC 座拔掉 —— START 板的 LDO 会顺带把载板 3.3V 反灌供起来，
    逻辑（INA228 / OLED / 网口）能跑；但 5V 那一路没有，**继电器不吸合、蜂鸣器和灯不动作**，
    要测声光报警还是得给 12V。
  - 已知取舍：**12V 电池和 USB 同时插时，两片 AMS1117 输出对顶**（还可能顺着 START 板 LDO 往 USB 的 VBUS 倒灌）。
    现场别这么用；真要同时用，就回到"加跳线"的方案。
- 载板经 JP6-2 给 START 板供电时，还要带上板载 GD-Link（GD32F103，约 20~30mA）；
  AMS1117（1A）与 MP1584（3A）都绰绰有余。
- 外设一律走载板自供电：START 板 3V3 那条路受板上 500mA 自恢复保险丝限制，不要在它上面挂外设。
- **电池与充电（安全底线）**：（电池为**充放电双口**，2026-10-11 确认，充电口与放电口分开）
  - 12V 锂电必须用**配套的专用充电器**充（3S 锂离子满电 12.6V，12V LiFePO4 满电 14.6V），
    **绝对不能用普通 12V 电源适配器直接充**——本作品要防的就是过充，方案里不能自己踩这个坑。
  - 充电口（DC 母头）装在外壳外面，充电回路**不经过载板**。
  - **保险丝按 2026-10-11 决定不加**：依赖电池包自带 BMS 的短路保护。若后面想补，电池正极就近串一个
    0.5~1A 自恢复保险丝即可（PCB 上留两个焊盘位置更省事）。
  - 续航估算：载板+主控约 160mA@12V（继电器常励磁占大头），3Ah 的 12V 包约能撑 18 小时，答辩够用。
  - 建议同时准备一个 12V 适配器当现场备用（接口与充电口区分开，别混插）。
- 原「24V 自取电」方案作废（历史记录保留在 v0.2/v0.3 的修订说明里）。

**上电前必须人工确认的 4 件事**（板上没有提示，靠万用表和模块丝印）：

1. **DC 座极性**：万用表通断档，一支表笔插进座的中心孔，另一支分别碰 1 / 2 / 3 脚焊盘，
   确认哪个焊盘是中心针。现按 `1 脚 = 12V_IN`、`2 脚 = GND` 接；**3 脚是开关脚，留空，不要接地**
   （把开关脚接地，没插插头时会把正负极短起来）。
2. **网口模块**：现在 1 脚(3.3V) 和 2 脚(5V) 都接了。确认模块是不是"5V 进、自带 LDO"的版本——
   如果是，建议把 1 脚断开，否则模块自己的 LDO 与载板 3.3V 会对顶。
3. **报警灯模块座 U11（1×3）**：现接 `1=GND、2=5V、3=LED_CTRL`，按模块丝印核对顺序。
4. **蜂鸣器极性**：现接 `1=5V、2=BUZZ_N`；若实物 "+" 在另一脚，两根线对调即可（接反只会不响，不烧）。

### 3.2 电流检测（INA228）

| 元件 | 参数 | 说明 |
|---|---|---|
| R_shunt | 2mΩ / 3W / 2512 | 5A 时压降 10mV、耗散 50mW（实物 LMN25HF3P0R002S，C41406285） |
| U3 | INA228AIDGSR（VSSOP-10） | 85V 共模，20 位 ΔΣ |
| 输入滤波 | 2 x 10Ω + 100nF 差分 + 10nF 对地 | 截止约 160kHz |
| I2C 上拉 | 4.7kΩ x 2 -> 3.3V | 与 OLED 共用 I2C1，不冲突 |
| 地址 | A0/A1 接地 | 0x40（OLED 0x3C） |
| ADC 量程 | VSHUNT = ±40.96mV | 对应 ±20.5A，LSB 约 0.039mA |

**功率路径**（分流电阻放在最前，共模恒定）：

```
J1(24V+) -> F1 -> D1 -> R_shunt -> K1(COM->NC) -> J2(负载+) -> 负载 -> J2(负载-) -> 电源 -
```

分流电阻紧贴电源侧，即使继电器断开，INA228 的共模也稳定在 24V。

### 3.3 断电与输出驱动

| 通道 | 器件 | 驱动方式 | 极性 |
|---|---|---|---|
| 继电器 K1 | 5V 线圈，1 组转换（等效 JQC-3FF-S-Z） | NPN S8050 + 1kΩ 基极 + 10kΩ 下拉 + 1N4148 续流 | 高电平吸合（**需重新定标**） |
| 蜂鸣器 | 有源蜂鸣器 | NPN S8050 + 1kΩ 基极 + 10kΩ 下拉 | **高电平导通**（改为低边驱动，与原方案相反，宏需反转） |
| 报警灯 | LED 模块信号脚（模块自带驱动） | 直连排针，不加三极管 | 高电平触发（沿用） |

> **重要**：由"裸器件直连"改为"三极管驱动"会改变触发极性。固件中的
> `FIREEYE_RELAY_ACTIVE_LOW`、`FIREEYE_BUZZER_ACTIVE_HIGH`、`FIREEYE_LED_ACTIVE_HIGH`
> 三个宏必须上板实测后重新定标，不可沿用旧值。

> **已决定（2026-10-11）：继电器改用常开（NO）接法**（原为常闭，按保护逻辑改过来）。
> 接法为 `COM(3) → NO(2) → LOAD_P`，NC(5) 留空：**励磁才导通；掉电、复位、报警都会自动断开负载**。
> - 这才是保护类设备真正意义上的"失效安全"：板子死机或断电时负载被切断。
> - **固件极性要反一次**：原先是"报警→吸合（断开）"，现在是"正常→吸合（导通）、报警→释放（断开）"。
>   应用层的 `gd32_fireeye_set_relay(true/false)` 语义不变（`true`=断开负载、`false`=恢复），
>   只需要把**板级实现里的 GPIO 电平映射反过来**。
> - 正常充电时线圈常励磁 71mA（耗电与之前报警后相同），报警后线圈释放、反而更省电。

### 3.5 采样抗干扰（解决电流检测偏差的关键）

原实测问题：继电器线圈 70mA 与传感器共用供/地路径，产生约 1.12A 的假底数（改线后残留 0.12A）。

载板对策（**最终版本见第八章 8.5，本节只列结论**）：

1. **单一地**：全板只用**一个 GND 网络**，不做 GND_P / GND_S 分割（理由见第八章）；
2. **开尔文接法**：INA228 的 IN+/IN- 从分流电阻焊盘内侧取样，走等长差分对；
3. **回流路径在布局层面分离**：继电器线圈、蜂鸣器、报警灯的回流走板下区，不横穿采样区、不与差分对平行；
4. **功率与信号分区**：24V/2A 大电流路径走板的一侧，信号走另一侧，中间用地铜隔离。

### 6.4 精度实验方案（三位半万用表的限制）

三位半万用表直流电流档典型精度为 ±(1.0%+2 字)、2A 档分辨率 1mA，
而 INA228 的目标精度优于 ±0.5%。**拿它当标定基准是非对称的，不做绝对精度对比。**

改用两条可执行的路线：

1. **读数抖动对比**（主推，不需要外部标准）：同一电流工况下各采 60 秒，
   分别统计旧方案（ACS712）与新方案（INA228）读数的标准差与峰峰值，
   结论写成"读数波动从 ±xx mA 降到 ±x mA"。这是自比较，不受万用表精度影响。
2. **量级核对**（辅助）：用万用表确认电流大致在设定值附近（如设定 1.75A、实测 1.7~1.8A），
   只用于证明"量级正确"，不声明精度。

如果后续能借到四位半万用表，再补做"设定值 vs 读数"的线性度曲线。

> **答辩口径提醒**：旧方案"读数只有 6~7 个 ADC 码"的论证基于 **0.15A** 的老负载；
> 现在演示电流是 **24V / 1.75A**，同样条件下 ACS712 有约 71 个码。答辩时不要沿用"6~7 个码"的说法，
> 统一按 1.75A 口径：ACS712 单码 ≈ 24mA，INA228 单码 ≈ 0.039mA（约 625 倍差距）。
> 造成旧方案"实测 1.12A 假底数"的地线耦合问题与负载大小无关，这条论据可以继续用。

### 8.5 抗干扰设计要点

**采样链路（最关键）**

1. **开尔文连接**：R2 / R3 从 R1 的焊盘**内侧**引出，不借用功率走线；这是消除走线电阻误差的根本手段。
2. **差分对**：INA_INP / INA_INM 两条线等长、平行、间距固定、面积最小；中途不换层、不打过孔（必须换层时两条线一起换）。
3. **滤波就近**：C3（100nF 差分）与 C4/C5（10nF 共模）紧贴 U3 的输入脚，走线总长控制在 10mm 内。
4. **避让**：差分对与 SW 节点、L1、继电器线圈回路的间距不小于 5mm，且不平行走线。

**开关电源**

5. **SW 节点面积最小化**：这是最强的辐射源，铜箔面积越小越好，且不引长线。
6. **紧贴布局**：C1 贴 U1-IN、L1 与 C2 贴 U1-SW，回路面积最小。
7. **远离敏感区**：L1 与 U3、NTC 分压、I2C 走线的距离尽量远。

**继电器与感性负载**

8. **续流二极管紧贴线圈**：D2 到线圈两端的走线尽量短，抑制断开瞬间的反向尖峰。
9. **线圈回流路径**：5V -> 线圈 -> Q1 -> GND 这条回路走板下区，**不穿过采样区**，也不与差分对平行。
10. **可选 RC 吸收**：若断开时仍有尖峰影响，可在线圈两端并联 100Ω + 100nF。

**通信与数字**

11. **I2C**：4.7kΩ 上拉；走线远离 SW 与线圈；若有振铃可串 33Ω。
12. **SPI**：W5500 的四条线走短线，不跨分割区，不与差分对平行；必要时串 22-33Ω。
13. **去耦**：每个 IC 的电源脚就近放 100nF；U1 输入 10µF + 100nF；U2 输入/输出各 10µF。

**结构与外壳**

14. OLED 与 RJ45 的排线在载板边缘就近引出，避免长距离绕行；OLED 的 I2C 排线远离功率走线。
15. 功率区（下区）与信号区（左区、板下贴片区）在各层做物理分隔。

### 9.4 画图顺序建议

1. **先放机械件定坐标**：两个 START 板母座（按 7.3 的坐标，第 1 脚在下端）、J1、J2、K1、OLED 座、W5500 座；
2. **再放功率链**：F1 → D1 → R1 → K1，走线宽度按 2A 留余量（1oz 铜建议 2mm 以上）；
3. **放采样支路**：R2/R3 从 R1 焊盘内侧引出，接 U3 输入，C3/C4/C5 紧贴 U3；
4. **放电源**：U1 及外围、U2，注意 SW 节点面积最小；
5. **放驱动**：Q1/Q2 及基极电阻、续流二极管 D2；
6. **最后连信号**：I2C1、SPI1、GPIO、UART，全部用**网络标号**连接，不拉长线；
7. **逐条对照第八章网表核对**，重点核 GND 是否有遗漏。
