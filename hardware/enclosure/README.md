## 三、内部结构

### 载板固定：四面卡槽

板上无安装孔，用四面卡槽限位：

- 槽宽 2.2 mm（板 1.6 + 公差 0.6）
- 槽深 2.0 mm
- 槽中心离内腔底面 **Z = 3.8 mm**
- 四边：左壁 / 右侧导轨（X=105）/ 下壁 / 上壁

### START 板支撑：4 根 φ8 柱

| 位置（载板坐标） | 柱顶高度 |
|---|---|
| (4, 45) (4, 125) | Z = 13.1 |
| (72, 45) (72, 125) | Z = 13.1 |

柱顶贴 1mm EVA 胶带软接触。**不放覆盖区正中间**（下方有 U5/U6 母座和 H1）。

### W5500 模块支撑平台（必须）

模块悬空 12.4mm（接近自身宽度一半），插拔网线力矩全压在 10 个排针焊点上。

| 项 | 值 |
|---|---|
| 位置 | X 105–119，Y 3–55（紧贴载板右缘） |
| 高度 | **顶面 Z = 12.6mm**（= 4.6 + h12 − 4，做矮，贴 5mm EVA） |
| 贴面 | 5mm EVA 泡棉 |
| **M3 锁固** | 平台超出板边那块（X 105–119）立 **4mm 矮柱** + **Φ2.5 底孔**，对准模块右孔 (116.4, 9.0)；M3 从模块 Φ3 孔穿下拧进矮柱（偏紧可换 M2.5）；左孔 (90.4) 在载板正上方不立柱 |

> 平台**不要精确顶住模块**。打印公差 ±0.2mm，做高了顶起模块导致接触不良；泡棉压缩 1–2mm 后刚好托住。
> 平台 Y 范围与 RJ45 缺口错开，不挡网线插入。
> M3 矮柱锁在平台超出段（板边 X105 以外），不挡载板滑入；配合平台 + EVA 共同承托。

## 五、开孔清单（按壁）

**底面（Y=0，接线侧，挂壁朝下）**

- **缺口 A**（合并）：X 1–30 × 高 10，通到底边 — U7 24V + U8 负载
  - **外壁标识**：开口上方阴刻 `24V IN` @ X8、`LOAD` @ X22.2（Z=18，字高 4.5）
- **缺口 B**（合并）：X 56–72 × 高 10，通到底边 — DC1 + LED1（φ5.2 透光）
- **RJ45 封闭方窗**：17×15 @ x 94.4~111.4、Z 19.4~34.4（对准接口 15×13）

> 24V/负载两口相距仅 14mm、DC/LED 同样紧邻，各自开孔中间只剩纸片薄壁 → **必须合并**。
> RJ45 窗按实测收口：接口宽 15、高 13，模块居中（两边各 6mm）。右侧到内腔壁还有 ~9mm 实体，封闭方窗做得到。

## 七、打印建议

| 项 | 建议 |
|---|---|
| 材料 | PLA（室内）；户外/高温用 PETG |
| 层高 | 0.2 mm |
| 壁厚 | 2.2 mm（5–6 圈） |
| 填充 | 15–20%；卡槽/柱/耳位置加实心 |
| 支撑 | 避免大面积悬空；开口边缘 0.5mm 倒角 |
| 公差 | 卡槽、柱与板之间 0.3–0.5mm |

## 八、装配顺序

1. 载板 + START 板 + W5500 模块**先在壳外插好**（START 76 针插拔力 4–8kg）
2. 整组沿卡槽滑入底壳（W5500 悬空段搁在平台上，贴 EVA）
3. 线缆从底面缺口 A/B 穿出；网线从 RJ45 封闭方窗插入
4. 扣前盖，四角 M3 螺丝拧入边仓柱孔
5. 挂壁：键孔对准墙面螺钉
