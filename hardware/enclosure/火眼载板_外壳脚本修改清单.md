## 一、外壳宽度不够（致命）

### 现状

```scad
out_w = pcb_w + 2*pcb_clr + 2*wall;   // 105 + 0.8 + 5 = 110.8mm
```

板右边缘到外壳右外壁只有 `0.4 + 2.5 = 2.9mm`，而 W5500 模块**探出板右边缘 12.4mm**。

### 修改

在 `pcb_clr` 附近增加一个"模块区"变量，并把 `out_w` 与载板偏移量一起改：

```scad
/* ---------- 选件 ---------- */
mod_over = 13.0;   // 新增：W5500 模块探出板右边缘的量(+0.6 余量)

/* ---------- 外轮廓 ---------- */
// 改前：out_w = pcb_w + 2*pcb_clr + 2*wall;
// 改后：
out_w = pcb_w + 2*pcb_clr + 2*wall + mod_over;   // 123.8mm
out_l = pcb_l + 2*pcb_clr + 2*wall;              // 145.8mm 不变
```

**注意：载板不居中，靠左对齐。** 脚本里 `dx = wall + pcb_clr;`（载板距外壳左外壁 2.9mm）**保持不变**，超出的 13mm 全部留在右侧。

## 二、四角螺丝柱压 PCB / 撞端子（致命）

### 现状

```scad
screw_inset = 5.0;
screw_boss_d = 8.0;
screw_pos = [ [5,5], [out_w-5,5], [5,out_l-5], [out_w-5,out_l-5] ];
```

柱子中心距外轮廓 5mm，而 PCB 距外壳内壁只有 0.4mm —— 柱子有约 4mm 压在 PCB 上（PCB 是整块矩形，无处避让）。

其中 `[5, out_l-5]` 那根，换算到载板坐标是"距左 5mm、距下 4.2mm"，**正压在 U7 的 24V 端子上**（端子中心距左 8.0、距下 5.8，本体约 10×8mm）。

### 修改（推荐：四角外凸螺丝耳，不占内腔）

不再把柱子放在内腔里，改成**外壳四角向外凸出一块"耳"**，螺丝孔开在耳上：

```scad
/* ---------- 螺丝耳（外凸，不占用内腔） ---------- */
ear_d      = 11.0;   // 耳的外径
ear_center = 6.0;    // 耳中心距外壳外轮廓角的距离
ear_h      = 12.0;   // 耳的高度（从下盖底面起）

// 四个耳的中心（相对外壳外轮廓左上角）
ear_pos = [
  [ ear_center,              ear_center ],
  [ out_w - ear_center,      ear_center ],
  [ ear_center,              out_l - ear_center ],
  [ out_w - ear_center,      out_l - ear_center ]
];

module screw_ears() {
    for (p = ear_pos)
        translate([p[0], p[1], 0])
            difference() {
                cylinder(d = ear_d, h = ear_h, $fn = 40);
                translate([0, 0, -0.1])
                    cylinder(d = screw_d, h = ear_h + 0.2, $fn = 24);
            }
}
```

然后把 `bottom_shell()` 里原来的 `screw_boss()` 循环整个删掉，改成：

```scad
// 在 difference 之外的 union 里加上
translate([0,0,floor_t]) screw_ears();
```

**验证要点**：
- 右下角的耳（`[out_w-6, out_l-6]`）会落在模块超出的那 13mm 区里 —— 那里正好是空的，**没有任何器件**，可以放
- 左下角的耳（`[6, out_l-6]`）虽然在 U7 端子的正外侧，但因为耳是**向外凸**的、不进入内腔，所以不会撞到端子本体

> 如果你更希望"不外凸、外观平整"，那就得把外壳四周统一加宽 6mm（内腔 117×152、外轮廓 122×157，再加右侧 13mm 后是 135×157）。代价是外壳大一圈。

## 三、RJ45 开口位置偏 7mm（致命）

### 现状

```scad
u9  = [96.3, 86.5];
translate([dx+u9[0]-rj45_w/2, out_l-wall-0.1, floor_t+term_z-1])
    cube([rj45_w, wall+0.2, rj45_h]);
```

按排针位置（96.3）开孔，但 RJ45 插座的中心在**模块宽度中心**，实际落在 **x ≈ 103.4mm（已超出板右边缘 6.2mm）**。

### 修改

```scad
/* ---------- 接口开孔 ---------- */
// 新增：RJ45 实际中心（= 载板坐标下模块宽度中心）
rj45_cx = 103.4;        // 距载板左边缘
rj45_cy = 86.5;         // 距载板上边缘（沿用 u9 的 Y）
rj45_w  = 16.5;         // 开口宽（插座 15.5 + 余量）
rj45_h  = 15.0;         // 开口高（含网线卡扣空间）

// 开孔改成：右下角开放式缺口，而不是封闭方孔
difference() {
    bottom_shell_body();
    // 从底面往上 25mm、从 X=当前RJ45左边缘一直通到外壳右下角
    translate([dx + rj45_cx - rj45_w/2, out_l - wall - 1, floor_t + term_z - 1])
        cube([rj45_w/2 + mod_over + wall + 2, wall + 2, rj45_h]);
}
```

**为什么改成开放缺口**：RJ45 右边缘距板边只剩 1mm，模块又探出 13mm，若做封闭方孔，外壳右侧壁只剩不到 1mm 厚，打印出来一碰就断。开放缺口同时容纳了 RJ45、模块悬空段和网线插拔空间。

## 四、U7 / U8 / NTC 出线槽开错面（严重）

### 现状

```scad
// 开在底壁（Z = 0 ~ floor_t 那一层）
translate([dx+u7[0]-wire_slot_w/2, dy+u7[1]-wire_slot_h/2, -0.1])
    cube([wire_slot_w, wire_slot_h, floor_t+0.2]);
```

Z=0 那一面是**与载板平行的大面**（挂墙后朝向墙或朝向外面）。而 U7/U8 是**侧面进线**的螺钉端子，导线应该朝**载板下边缘**方向出去 —— 挂在墙上就是朝下。

### 修改

把这三个槽从"底壁"移到 **`out_l` 侧壁**（`Y` 最大侧，脚本里注释为"前侧，挂壁朝下"）：

```scad
// 以下三块替换原来开在 Z=-0.1 的三个 cube

// U7 24V 端子出线槽（开在 Y 最大侧壁上）
translate([dx+u7[0]-14/2, out_l-wall-1, floor_t+term_z+1])
    cube([14, wall+2, 12]);

// U8 负载端子出线槽
translate([dx+u8[0]-14/2, out_l-wall-1, floor_t+term_z+1])
    cube([14, wall+2, 12]);

// NTC 引线槽（NTC 座在板中部，线要引到板边再出去 —— 见下方说明）
// 若线从 NTC 座直接就近引出，改用上盖开孔（见第五节）
```

**关于 NTC**：`h2 = [74.7, 81.0]` 是载板**中部**的位置，离任何一边都远。载板上的 NTC 座到外壳下边缘有约 60mm，线要在壳内走一段。两个选择：

1. 从**上盖**开 φ4mm 孔就近引出（推荐，线短）
2. 从下边缘侧壁开孔，线在壳内走 60mm（占用内部空间）

建议选 1，把 h2 的开孔从底壁移到上盖。

## 五、LED1 没有开孔（严重）

### 现状

```scad
led1 = [68.7, 135.0];     // 定义了，注释写"上盖透光"
```

但 `bottom_shell()` 和 `top_shell()` 里**都没有引用 `led1`** —— 电源指示灯会被外壳完全挡住。

```scad
    rotate([-90,0,0]) cylinder(d=5.4, h=wall+2, $fn=24);
```

## 六、START 板开窗位置偏 5.4mm（严重）

### 现状

```scad
start_cx = (u5[0] + u6[0]) / 2 + 0.55;
start_cy = (u5[1] + u6[1]) / 2 + 0.1;
```

按"母座中心 = START 板中心"推算位置。但 START 板上两个母座是**不对称**的：

- 第 38 脚（排针上端）距板上边缘 **30.0mm**
- 第 1 脚（排针下端）距板下边缘 **19.3mm**
- 所以母座中心距板上边缘 = 30.0 + 45.72/2 = **52.86mm**，而不是板长的一半 47.5mm

误差 = 52.86 − 47.5 = **5.36mm**。

### 修改

```scad
/* ---------- START 板覆盖区（按不对称母座推算） ---------- */
start_w = 60.0;      // START 板宽
start_l = 95.0;      // START 板长
start_pin_to_top = 52.86;   // 母座中心距 START 板上边缘（= 30.0 + 45.72/2）

// X 方向：两母座中心连线的中点即板中心（X 方向对称）
start_cx = (u5[0] + u6[0]) / 2 + 0.55;
// Y 方向：母座中心往下推 start_pin_to_top 才是板上边缘
start_y_top = (u5[1] + u6[1]) / 2 + 0.1 - start_pin_to_top;
start_y_bot = start_y_top + start_l;
start_x_left  = start_cx - start_w/2;
start_x_right = start_cx + start_w/2;
```

上盖开窗改为引用新的上下边界：

```scad
translate([dx+start_x_left-1, dy+start_y_top-1, -0.1])
    cube([start_w+2, 32, lid_t+0.2]);   // 32 = USB / GD-Link 那一侧的高度，可保留
```

## 七、PCB 只有托台、没有限位（中）

### 现状

```scad
pcb_clr = 0.4;   // 板周间隙
```

载板在四边托台上（高 8.5mm），四周 0.4mm 间隙，上盖的止口压不到它 —— 挂墙后板子会在托台上滑动，插拔端子时会推动整块板。

### 修改（二选一）

**方案 A（简单）**：把间隙收小到 0.15mm

```scad
pcb_clr = 0.15;
```

**方案 B（推荐）**：把托台改成"卡槽"——在载板上下边缘各加两条限位筋

```scad
module pcb_supports() {
    rail_h = pin_clr;
    // 保留左右托台（承重）
    for (x=[dx-0.1, dx+pcb_w-3+0.1])
        translate([x, dy+5, floor_t]) cube([3, pcb_l-10, rail_h]);
    // 上下托台改成"限位筋"（高出众托台 1.5mm，卡住板边）
    for (y=[dy-0.1, dy+pcb_l-3+0.1])
        translate([dx+5, y, floor_t]) cube([pcb_w-10, 3, rail_h+1.5]);
}
```

## 12. 四角螺丝耳要真正"外凸"（第一轮第 2 条没改到位）

### 问题

```scad
ear_c = 6.0;
for (sx = [ear_c, out_x - ear_c], sy = [ear_c, out_y - ear_c])
    translate([sx, sy, 0]) cylinder(d=ear_d, h=h, $fn=40);
```

耳中心 (6, 6)、内腔原点 (2.2, 2.2) → 换算到载板坐标是 **(3.8, 3.8)**，直径 11mm。
而 U7 端子（`u7 = [8.0, 5.8]`，KF128-5.08-2P 本体约 10.2×8mm）占载板坐标 **X 2.9~13.1、Y 1.8~9.8**。

两者重叠 **X 2.9~9.3、Y 1.8~9.3**，Z 方向也重叠（耳 0~12，端子 4.3~14.3）—— **左下角这根耳装不进去**。

### 修改（二选一）

**方案 1：耳真正外凸**（外壳保持紧凑）

```scad
// 耳中心移到内腔边界之外
ear_c = 9.5;      // 原 6.0；需满足 ear_c - ear_d/2 ≥ wall + 少量余量
                   // 9.5 - 5.5 = 4.0 > wall(2.2) ✓ 耳不再伸入内腔
```

**方案 2：四周加宽边仓**（外观平整，外壳大一圈）

```scad
wall_bay = 6.0;   // 新增：内腔与外轮廓之间的"边仓"宽度
out_x = cavity_x + 2*(wall + wall_bay);   // 124.4 → 136.4
out_y = cavity_y + 2*(wall + wall_bay);   // 149.4 → 161.4
```

> 注意：选方案 2 时，`dx/dy`（内腔原点）要同步改成 `wall + wall_bay`。

## 13. 卡槽起点写错，载板滑不进去（第一轮第 7 条没改到位）

### 问题

```scad
translate([-0.1, dy - 0.5, dz + slot_zc - slot_w/2])
    cube([slot_d + 0.1, pcb_l + 1.0, slot_w]);
```

该立方体占 **X −0.1 ~ 2.0**，而内腔从 **X = dx = 2.2** 开始。
→ 切完之后 X 2.0~2.2 还剩 **0.2mm 的薄壁**挡着，载板放不进去。

### 修改

起点从"外壳外壁"改为"内腔面"：

```scad
// 左壁
translate([dx - slot_d, dy - 0.5, dz + slot_zc - slot_w/2])
    cube([slot_d + 0.1, pcb_l + 1.0, slot_w]);
// 下壁
translate([dx - 0.5, dy - slot_d, dz + slot_zc - slot_w/2])
    cube([pcb_w + 1.0, slot_d + 0.1, slot_w]);
// 上壁
translate([dx - 0.5, dy + pcb_l, dz + slot_zc - slot_w/2])
    cube([pcb_w + 1.0, slot_d + 0.1, slot_w]);
```

**同时把 `slot_d` 从 2.0 降到 1.2**——壁厚只有 2.2mm，切 2.0mm 后外壁只剩 0.2mm，一碰就破。（或者把 `wall` 从 2.2 加到 2.5，`slot_d` 保持 2.0。）

> 右侧那条（`dx + pcb_w - slot_d`）切在空气里（右侧没有实体壁），可以删掉——模块支撑平台已经在 X 105~119 起了右侧限位作用。

## 14. 模块支撑平台超出内腔

```scad
plat_x1 = 123.0;   // 内腔 cavity_x = 120
```

平台比内腔宽 3mm，模型上会顶进右侧壁、并凸出外轮廓约 0.8mm。

**改**：

```scad
plat_x1 = 119.0;   // 内腔留 1mm 余量
```

## 15. 底壳背面的散热孔会被墙挡住

README 里写明"底壳背面（Z=0，**贴墙面**）散热孔 ×4"——挂壁键孔也开在 Z=0 面，说明 Z=0 就是贴墙那一面。**开在贴墙面的孔吸不到风**，等于白开。

**改**：把这一组从 Z=0 面移到**上侧壁**（`Y = cavity_y` 那一面，挂墙后朝上），与前盖那组形成上下对流：

```scad
// 底壳：上侧壁通风孔（替代原来的 Z=0 面开孔）
for (v = vents)
    translate([dx + v[0], dy + cavity_y - 0.1, -0.1])
        rotate([-90, 0, 0])
            cylinder(d=vent_d, h=wall + 0.2, $fn=20);
```

> 前盖那组保留不动。

## 16. 加装电源拨动开关（方案 A：不改板，外接开关线）

### 背景

载板上没有任何电源开关，12V 输入是 DC 座直连 C10/MP1584。板子已打样，**不改板**，用外接开关线解决。

### 器件

| 项 | 建议 |
|---|---|
| 开关类型 | **面板安装型拨动开关**，如 MTS-102（单刀双掷）|
| 螺纹/开孔 | M6×0.75，**开孔 Φ6.2mm** |
| 额定 | 3A/125VAC 以上（实际只走 12V / 0.2A，余量很大）|
| 线材 | 买"**DC 5.5×2.1 公转母 带开关 延长线**"，或自制：DC 公头 + 线 + 开关 + 线 + DC 母头 |

### 接线

```
12V 锂电池 → DC 公头 → [拨动开关] → DC 母头 → 载板 DC1（穿过缺口 B）
```

### 外壳开孔

```scad
/* ---------- 电源开关（拨动开关 MTS-102） ---------- */
sw_x = 18.0;      // 载板坐标
sw_y = 60.0;
sw_d = 6.2;       // 开孔直径（M6 螺纹 + 0.2 余量）

// 加在 front_cover() 的 difference 里
translate([dx + sw_x, dy + sw_y, -0.1])
    cylinder(d=sw_d, h=cover_t + 0.2, $fn=32);
```

**位置校验**（前盖上现有开口）：

| 已有开口 | 位置 | 与 (18, 60) 的距离 |
|---|---|---|
| OLED 窗 | (38.1, 102.4) | 47mm ✓ |
| 蜂鸣器 | (91.7, 95.8) | 81mm ✓ |
| 报警灯 | (89.8, 115.9) | 90mm ✓ |
| NTC | (74.7, 59.0) | 57mm ✓ |
| 散热孔 | (20, 18) | 42mm ✓ |

✓ 位置干净，没有干涉。

**内侧空间校验**：开关本体伸入壳内约 15mm（Z 32.2 → 17.2），载板在 Z 2.7~4.3，继电器顶点 Z 20.1（位置 (41.9, 18.8)，距开关 47mm）—— 都不干涉 ✓

### 备选位置（若希望开关在侧面而不是前盖）

右侧壁（`X = out_x` 面），载板坐标 **Y 100~130、Z 15~25** 一带：
- 该区域载板 X 只到 105，内腔到 120，有 15mm 空档 ✓
- 避开右下角开放缺口（Y 0~25）和 W5500 模块（Y 26~81）✓
- 缺点：挂墙后开关朝侧面，操作不如前盖顺手
