# 火眼载板 · 3D 打印外壳设计规格

> 版本 v1.0 ｜ 2026-10-14
> 用途：交付建模（人工或 AI 建模工具）的输入规格
> 硬件状态：载板已打样；W5500 排针位置存在偏差，需靠外壳补救

---

## 一、装配方式

- **PCB 竖直放置**（板面平行墙面），挂壁安装
- 外壳分 **底壳 + 前盖** 两件，M3 螺丝固定（建议 M3×12，4 颗）
- 前盖必须可拆：START 板插在 76 针母座上，插拔力约 4~8kg，需要开壳操作
- **装配顺序**：载板 + START 板 + W5500 模块先在壳外插好 → 整组放进底壳 → 扣前盖

---

## 二、基准坐标系

**以内腔底面左下角为原点**（建模统一用这个基准）：

| 轴 | 方向 | 范围 |
|---|---|---|
| X | 向右 | 0 ~ 120mm |
| Y | 向上 | 0 ~ 145mm |
| Z | 垂直板面（朝前盖方向为正）| 0 ~ 30mm |

载板在内腔中的位置见第四节。

## 四、PCB 定位

### 载板

| 项 | 数值 |
|---|---|
| 尺寸 | 105 × 140 × 1.6mm |
| 位置 | 内腔 **左下角对齐**（X 0~105、Y 0~140）|
| 固定方式 | **四面卡槽**（板上没有安装孔）|
| 卡槽规格 | 槽宽 2.0mm、槽深 2.0mm、**槽中心离内腔底面 3.8mm** |

> 卡槽离底 3.8mm 是给载板背面的通孔元件引脚留空间（母座、端子引脚突出约 1~2mm）。
> 即：载板底面 Z=3.0mm，载板顶面 Z=4.6mm。

### 载板上器件的朝向

- 元件面朝**前盖**（Z 正方向）
- 底边（Y=0）对应端子的接线方向朝下

## 六、W5500 模块区域（重点）

### 现状

| 项 | 数值 |
|---|---|
| 模块尺寸 | 55 × 28mm |
| 座子 U9 位置 | (96.3, 53.5) |
| 模块 x 范围 | 89.4 ~ 117.4mm |
| **模块右边缘超出板右边缘** | **约 12.4mm** |
| RJ45 插座 x 范围 | 95.6 ~ 111.2mm |
| **RJ45 右边缘超出板右边缘** | **约 6.2mm** |
| RJ45 插座 y 范围 | 距板下边缘 3.5 ~ 24.5mm |

### 开口做法

**在右下角做一个开放式缺口**（不是封闭方孔）：

```
从底面（Y=0）往上切 25mm
从 X=95mm 一直通到外壳右下角
```

原因：RJ45 右边距板边只剩 1mm、模块又探出 12.4mm，做封闭方孔会留下"纸片一样薄"的侧壁，一碰就断。开放缺口同时解决：RJ45 伸出、网线插拔空间、模块悬空段的空间。

### 支撑平台（必须做）

模块悬空 12.4mm（接近自身宽度的一半），插拔网线的力矩全压在 10 个排针焊点上。

**在内腔底面右侧做一块平台**：

| 项 | 数值 |
|---|---|
| 位置 | X 105 ~ 123mm，Y 3 ~ 55mm（紧贴载板右边缘，留 0.5mm 缝）|
| 高度 | **4.6 + h − 4mm**（h 见第十节），实际做矮 3~4mm |
| 顶面 | 贴 5mm 厚 EVA 泡棉 / 高密度海绵 |

> 关键：**平台不要做到精确顶住模块**。3D 打印高度公差 ±0.2mm，做高了会把模块顶起来导致排针接触不良；做矮了没支撑。用泡棉吸收公差，压缩 1~2mm 后刚好托住。

> 平台的 y 范围要与 RJ45 缺口错开，不要挡住网线插入通道。

## 七、START 板支撑

### 位置

| 项 | 数值 |
|---|---|
| START 板尺寸 | 60 × 95mm |
| 占载板范围 | X 8.7 ~ 68.7mm，Y 38.3 ~ 133.3mm |
| 插合净空 | START 板底面距载板顶面 **8.5mm** |

### 支撑方式

**在 START 板的左右两侧**做支撑柱（这两个区域载板上没有高元件）：

| 支撑柱 | 位置 | 高度 |
|---|---|---|
| 左侧 2 根 | X 0 ~ 8mm，Y 45 / 125mm | 顶部到 Z = 4.6 + 8.5 = **13.1mm** |
| 右侧 2 根 | X 69 ~ 76mm，Y 45 / 125mm | 同上 |

柱子顶部贴 1mm EVA 胶带（软接触）。

> 不要放在 START 板覆盖区正中间——那一片下方有 U5/U6 母座和 H1 座子。

## 八、散热

载板下区（Y 0 ~ 40mm）集中了 MP1584、AMS1117、继电器、分流电阻，是发热区。

| 位置 | 做法 |
|---|---|
| 底壳底面（Y 10 ~ 35mm 区间）| 开 4 个 Φ4mm 通风孔 |
| 前盖对应位置 | 开 4 个 Φ4mm 通风孔 |

## 九、打印参数建议

| 项 | 建议 |
|---|---|
| 材料 | PLA（室内够用）；户外/高温环境用 PETG |
| 层高 | 0.2mm |
| 壁厚 | 2.2mm（5~6 圈）|
| 填充 | 15~20%；支撑柱和卡槽位置加实心 |
| 支撑 | 避免大面积悬空；开口边缘做 0.5mm 倒角/锥形，减少支撑 |
| 装配公差 | 卡槽、柱子与板之间留 0.3~0.5mm 间隙 |

---

## 十、待确认项（建模前必须实测）

| # | 要测什么 | 为什么要 |
|---|---|---|
| 1 | **模块底面距载板顶面的高度 h** | 决定支撑平台高度（预计 7~9mm）|
| 2 | **START 板装上后最高的元件高度** | 决定内腔高度（当前按 30mm 估）|
| 3 | 模块超出板右边缘的准确量 | 当前按 12.4mm 算，确认后可微调内腔宽度 |
| 4 | 报警灯罩、蜂鸣器的实际外径 | 定 Φ7 / Φ9 开口 |

## 十一、建模提示词（可直接粘贴给 AI 建模工具）

> 说明：底面相邻开口已做合并优化——原设计里"24V 端子 (8.0)"与"负载端子 (22.2)"相距仅 14mm、各自要开 14mm 宽，中间只剩 0.2mm 会形成纸片薄壁；"DC 座 (61.8)"与"指示灯 (68.7)"同样挨得太近。**合并成两个大缺口**，结构强度好得多。

```text
请用 OpenSCAD 生成一个 3D 打印外壳的模型代码，用于装一块 105×140mm 的电路板。

【零件】
分两部分：底壳 + 前盖，用 4 颗 M3 螺丝固定（螺丝柱外径 φ6mm，M3 自攻孔）。

【总体尺寸】
- 内腔：120（宽 X）× 145（高 Y）× 30（深 Z）mm
- 壁厚：2.2mm；外壁圆角 R3，内腔圆角 R2
- 坐标系：内腔底面左下角为原点，X 向右、Y 向上、Z 朝前盖方向

【内部结构】
1. 载板卡槽：在 X 0~106、Y 0~141 范围内做四周卡槽
   槽宽 2.0mm、槽深 2.0mm、槽中心距内腔底面 Z=3.8mm
   （载板 105×140×1.6mm，卡槽比板略大便于装配）
2. START 板支撑柱 4 根：φ8mm，柱顶高度 Z=13.1mm
   位置中心：(4, 45)、(4, 125)、(72, 45)、(72, 125)
3. 模块支撑平台 1 块：X 105~123mm、Y 3~55mm，顶面高度 Z=8mm

【开口】（单位 mm，坐标为内腔坐标）
底面（Z=0 面，即底壳朝下那面）：
- 缺口 A：X 1 ~ 30 之间的开口，高度 10mm，通到底边（24V 输入端子 + 负载端子）
- 缺口 B：X 56 ~ 72 之间的开口，高度 10mm，通到底边（DC 电源座 + 电源指示灯）
- 右下角开放缺口：从 X=95 到 X=120、从底面往上 25mm 贯通（网口区域）

左面（X=0 的壁）：
- 以 Y=82.9 为中心，开一个 12（沿 Y）× 6（沿 Z）mm 的槽，穿透壁厚（调试串口）

前盖（Z=30 那面）：
- 中心 (38.1, 102.4)：22（X）× 12（Y）mm 窗口（OLED 屏）
- 中心 (91.7, 95.8)：φ9mm 圆孔（蜂鸣器）
- 中心 (89.8, 115.9)：φ7mm 圆孔（报警灯）
- 中心 (74.7, 59.0)：φ4mm 圆孔（NTC 引线）

【散热】
底壳底面和前盖各开 4 个 φ4mm 圆孔，均匀分布在 X 5~100、Y 10~35 的区间。

【代码要求】
- 所有尺寸定义成文件开头的变量，方便后续调整
- 每个开口边缘加 0.5mm 倒角
- 底壳与前盖之间做 0.3mm 的台阶定位，防止装配后错位
- 螺丝柱位置在底壳和前盖上对称
- 输出可直接运行的 OpenSCAD 代码，并在每个特征处写中文注释说明用途
```

> 如果所用工具不是 OpenSCAD（比如 CadQuery、Fusion 参数化、或纯 AI 文生 3D），把上面这段当**需求书**用即可——参数是完整的，换格式不影响。

### 提示词里没写、但建模时要留意的两点

1. **模块支撑平台的高度是"做矮"的**：这里写死 Z=8mm，实际装配时顶面要贴 5mm 厚 EVA 泡棉再托住模块。不要按"精确顶住模块底面（约 12.6mm）"来做。
2. **前盖上的四个开口位置**是按载板元件面投影给的。前盖单独拆成零件建模时，这四个孔的基准仍是"内腔左下角"，不是前盖自身的左下角。
