## 一、一句话概括这半个月改了什么

从"**24V 回路自取电 + ACS712 单端采样**"，改成"**12V 锂电池独立供电 + INA228 差分采样 + 继电器常开失效安全**"，并把 PCB 定为 **2 层板**、电源簇搬出主控板夹层、补上板载声光与测试点。

## 二、电源架构（最大的一处变更）

### 2.1 变更前后

| | 原方案 | 现方案 |
|---|---|---|
| 载板供电 | 24V 被测回路自取电（MP1584 接 24V_P） | **12V 锂电池 → DC5521 座 → MP1584(5V) → AMS1117(3.3V)** |
| 24V 的角色 | 既是被测回路，又是板子电源 | **只作被测回路** |
| 板子自耗 | 经 F1/D1 但**在分流电阻上游**，不进测量 | **完全不进被测回路** |
| 可调电源显示 | = 负载 + 板子自耗（差约 55 mA） | **= INA228 读数（一致）** |

### 2.2 为什么改

1. 消除"可调电源显示比 INA228 读数大几十 mA"的解释负担（评委交叉验证时最容易出问题的地方）；
2. 继电器、蜂鸣器、灯都由独立电池供电，24V 那一路只承担负载，演示口径干净；
3. 24V 回路断电（充电结束/拔负载）时，终端仍活着，可上报"电流归零/充电结束"事件 —— **自取电方案做不到，这是产品优势**。

### 2.3 具体接法【实测网表】

```
12V 锂电（充放电双口）→ DC 座(DC1, DC-005-5.5×2.1 / DC5521) → C10 → U2 MP1584 VIN
                                                                  ├ EN 由 R9 上拉到 12V_IN
                                                                  └ U2 5V 输出 → AMS1117 → VCC(3.3V)
被测回路：U7(24V 输入) → F1 → D1 → R1(2mΩ) → 继电器 COM → NO → U8(负载)
```

- `12V_IN` 网络 = {DC1-1, C10-1, R9-1, U2-VIN}；
- `24V_P` 只剩 {D1 阴极, R1-2, R3 采样串阻} —— **板子自耗彻底移出**；
- DC 座 **3 脚（开关脚）留空**，不要接地【设计】。

### 2.4 已决定的取舍

| 决定 | 内容 | 风险/代价 |
|---|---|---|
| **不加 3V3 LINK 跳线** | 载板 3.3V 直接经 JP6-2 送 START 板 | **12V 电池与 USB 不能同时插**（两片 AMS1117 对顶）；只能靠操作纪律 |
| **不加输入保险丝** | 依赖电池包自带 BMS | 无冗余保护；PCB 上建议留两个焊盘位以后补 |
| **电池为充放电双口** | 充电口在电池上、外置到外壳，充电回路不经过载板 | 必须使用**配套的锂电专用充电器**（3S=12.6V / LiFePO4=14.6V），**不能用普通 12V 适配器直充** |

### 2.5 调试模式的实际行为【设计】

拔掉 12V 电池、只插 USB 时：START 板的 LDO 会顺带把载板 3.3V 反灌供起来，逻辑（INA228/OLED/网口）能跑；但 **5V 那一路没有电**（MP1584 不工作），继电器不吸合、蜂鸣器与报警灯不动作。要测声光报警必须给 12V。

### 2.6 待决策【待确认】

`DC1` 的插入方向、以及"载板 3.3V 与 START 板 3V3 直连是否可接受"仍需在实物上确认；若坚持要能同时插 USB，需回到"加跳线"方案。

## 三、电流检测（ACS712 → INA228）

### 3.1 精度账（已复算）

| | ACS712-30A（旧） | INA228 + 2 mΩ（新） |
|---|---|---|
| 通道 | 单端（相对 GND） | **差分（IN+ / IN−）** |
| 等效灵敏度 | 66 mV/A，分压后 **33 mV/A** | 满量程 ±40.96 mV ↔ ±20.48 A |
| 单码电流 | 0.806 mV ÷ 33 mV/A ≈ **24.4 mA** | 78.125 nV ÷ 2 mΩ ≈ **39 µA（0.039 mA）** |
| 差距 | — | **约 625 倍** |

**必须区分**：0.039 mA 是 **ADC 分辨率**，不是精度；实际精度受分流电阻容差/温漂（±1% 常见）、增益误差（INA228 约 ±0.05%）限制，需软件标定或选 ±0.5% 电阻。

### 3.2 为什么差分能治"1.12 A 假底数"

分流电阻压降只有 **3.5 mV @1.75A**，且两点共同浮在 24V 上。单端方案把地线压降（继电器线圈 70 mA 流过地线）直接算进结果；差分只看 IN+−IN−，共模干扰被 CMRR（>100 dB）抵消。

### 3.3 采样链路的六条布局/布线规则【设计 + 实测支撑】

1. **开尔文**：只从 R1 焊盘**内侧**引出，不借功率走线；
2. **差分对**：`R3→U1 IN+`、`R2→U1 IN−` **并排、等长、同层、线宽 8 mil / 线距 8 mil**；
3. **两侧分别进脚**：U1 的 IN+/IN− 是 0.5 mm 相邻脚，一根从左进、一根从右进（实测按此可避免 8 mil 压线）；
4. **滤波件贴脚**：R2/R3（10Ω）、C4（100nF 差分）、C5/C6（10nF 共模）在 U1 输入脚 3 mm 内；C4 横跨两根线；
5. **地单独回**：C5/C6 的地只回 U1 的 GND 脚，不就近接铺铜；
6. **避让**：与 SW 节点/电感/继电器线圈 ≥5 mm 且不平行。

### 3.4 已完成实测（2026-10-12 快照）【实测】

- `INA_INM`：4 焊盘 / 10 段，**连通成 1 块** ✓
- `INA_INP`：曾断成 2 块（C4/C5 支路未接主干），需补一段；
- 开尔文支路 `R1→R3-2`、`R1→R2-2` 已布；
- 相邻脚触发的 19~20 mil 间距告警属 **0.5 mm 脚距固有**，可忽略。

> 10-23 之后布局有改动，以上坐标需重新读回核对。

## 四、继电器：常闭 → 常开（失效安全）

| | 原（NC） | 现（NO） |
|---|---|---|
| 接法 | COM(3)→NC(5)→LOAD_P | **COM(3)→NO(2)→LOAD_P**，NC(5) 留空 |
| 未励磁（掉电）时 | 负载**导通** ✗ 保护失效 | 负载**断开** ✓ |
| 正常工作时 | 线圈不励磁 | 线圈**常励磁**（约 71 mA） |
| 报警时 | 励磁→断开 | 释放→断开 |
| 演示效果 | 一样 | 一样 |

**固件同步**【已完成设计】：应用层已经移除“继电器 true=断电”的双关语义，
改为“负载接通/断开”；当前新板映射为 PB0 高电平励磁并接通负载，报警和掉电时释放。

> 答辩可主动讲："从常闭改常开是为了失电即断开，这是保护类设备真正的失效安全"。

## 五、W5500 网口座：1×7 → 2×5（10 脚）

- 现器件：`LAIL-PM2.54-5PX2-L`（2×5 直插），1/3/5/7/9 在左列、2/4/6/8/10 在右列；
- 引脚定义：`1=VCC(3.3V) 2=5V 3=MISO 4=GND 5=MOSI 6=RST 7=SCS 8=INT 9=SCLK 10=NC`；
- 6 条信号已改名为 `SPI1_MISO / SPI1_MOSI / SPI1_SCK / W5500_SCS / W5500_RST / W5500_INT`，与母座侧网络合并【实测】；
- **待确认**：1 脚（3.3V）与 2 脚（5V）是否都该接——若模块自带 LDO，建议只接 5V，避免两路电源对顶；
- **待确认**：2×5 排针的编号顺序需与模块丝印核对。

## 八、PCB 工艺与布线策略

### 8.1 工艺

| 项 | 值 |
|---|---|
| 层数 | **2 层**（顶层走线、底层整片 GND） |
| 板厚/铜厚 | 1.6 mm / 1 oz |
| 过孔 | 0.3 mm 孔 / 0.6 mm 盘 |
| 最小线宽/线距 | ≥8 mil（工艺 5 mil） |
| 加钱项 | 无 |

### 8.2 线宽（IPC-2221，1 oz，ΔT=10°C）

| 网络 | 电流 | 采用 |
|---|---|---|
| 24V 功率链 | 1.75 A | 1.5 mm（60 mil） |
| 线圈/续流 | 71 mA | 0.75 mm（30 mil） |
| SW 节点 | 0.3 A | 0.75~1.5 mm（越短越好） |
| 12V_IN | 0.16 A | 0.75 mm（30 mil） |
| 5V | 0.25 A | 0.65 mm（25 mil） |
| VCC(3.3V) | 0.15 A | 0.4 mm（16 mil） |
| 采样差分对 | — | 0.2 mm + 0.2 mm |
| 一般信号 | — | 0.2 mm（8 mil） |

### 8.3 关键策略（详细规则见 `pcb_layout_routing_rules.md`）

1. **铺铜永远最后做**（先铺后走线 = 处处绕不开，这是实际踩过的坑）；
2. **底层优先保持整片地**（采样区正下方必须完整）；底层走线只允许短段、且避开采样区；
3. **45° 折角**，禁直角/锐角；差分对折角对称；
4. 过孔白名单：GND/5V/VCC/12V/UART/SPI/GPIO/I2C；黑名单：采样差分对、SW、BST；
5. 通孔焊盘一律热焊盘；缝合过孔 ≤5 mm；
6. AMS1117 散热脚是 VOUT（3.3V），散热过孔要扎进 **VCC 铜岛**，不是地。

| W5500 模块 | 28 × 55 mm，RJ45 朝板边，排针在远离 RJ45 的一端 | 用户实测 |

### 9.1 布局方面的关键决定

1. **电源簇从 START 板夹层搬到开放区**：散热更好（总耗散约 0.5 W），也便于探针；
2. **采样簇紧贴 R1**（6~12 mm），离继电器线圈与开关电源尽量远；
3. **继电器最佳落点**：离采样区 ≥20 mm，离 R1 ≤25 mm（既不让大电流环路变长，也不让线圈噪声贴近采样）；
4. **板载声光/接口件贴板边**，与外壳开孔对应；
5. OLED 座曾落在 START 板覆盖区内（高 8~10 mm > 8.5 mm 净空）——**装配前必须确认不干涉**，否则挪到板边或给 START 板加高垫柱。
